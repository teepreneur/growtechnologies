# GrowTech website

Scalable hydroponic vertical farms that run entirely on solar power, built, installed and maintained in Accra, Ghana.

The site is a single page built around a live 3D simulation of a GrowTech farm (three.js). As visitors scroll, each section moves the camera, the clock or the farm size; the last section hands over full control.

- `index.html` – the page
- `farm-engine.js` – 3D scene and day/night energy simulation (planning figures, not measured data)
- `assets/` – logos and a render of the 3D farm

Served with GitHub Pages from the `main` branch.
