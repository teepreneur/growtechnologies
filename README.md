# GrowTech website

Hydroponic vertical farms that run themselves, built one version at a time. Made, installed and maintained in Accra, Ghana.

Live site: https://teepreneur.github.io/growtechnologies/

## Where we are
- **v1** (2023) – single layer hydroponics. Built.
- **v2** (2024) – our own stackable design: each layer works alone or stacked, and a pump lifts nutrient water from the bottom tank to the top so it runs down through every layer. Growing now; visits welcome.
- **v3** – solar power, sensors and a live dashboard. This is what the family-and-friends raise builds (Stage 1, GH₵ 60,000).
- **v4** – AI: crop recommendations, camera checks and automatic control. Future plan, not funded by this raise.
- **v5** – robotics: seeding, transplanting and harvesting. Future plan, not funded by this raise.

## The page
A single page built around a live 3D simulation of the farm (three.js). As visitors scroll, each chapter moves the camera, the clock or the farm size; a version switcher shows v2 to v5; the last chapter hands over full control. If a browser cannot show 3D, the clock and energy readings still run.

- `index.html` – the page
- `farm-engine.js` – 3D scene and day/night energy simulation (planning figures, not measured data)
- `assets/` – logos, a render of the 3D farm and the v2–v5 roadmap pictures

Served with GitHub Pages from the `main` branch.
